# 쿼터뷰 액션게임 (전투 테스트)

위에서 비스듬히 내려다보는 **쿼터뷰 실시간 액션** 프로토타입입니다.
기준 문서는 「캐릭터 컨트롤과 장르」(포트폴리오 PPT) — *복잡한 성장트리 대신 캐릭터 컨트롤과 직관적인 실시간 전투* 가 핵심입니다.

- 엔진: [LÖVE 11.x](https://love2d.org/) (Lua). 이미지 파일 없이 전부 코드로 그립니다.
- 화면: 참고 영상(직접 만든 언리얼 프로토타입)처럼 올리브 바닥 + 베이지 상자 벽 + 긴 그림자, 마네킹 캐릭터(흰 = 나, 빨강 = 적)
- 캐릭터는 3D 뼈대를 8방향으로 돌려서 그립니다 (`rig.lua`).

## 실행

1. LÖVE 11.x 설치 (Windows 기본 경로 `C:\Program Files\LOVE`)
2. 이 폴더를 실행: `"C:\Program Files\LOVE\love.exe" .`
3. exe 만들기: `powershell -ExecutionPolicy Bypass -File build.ps1` → `실행파일\쿼터뷰액션.exe`
   (exe 가 켜져 있으면 빌드가 막힙니다 — 창을 닫고 다시)

자동 테스트(가짜 입력으로 7개 스타일을 25초씩 플레이, 스크린샷 저장):
`"C:\Program Files\LOVE\lovec.exe" . --autotest`
→ 콘솔에 결과, 스크린샷은 `%APPDATA%\LOVE\quarterview\auto_*.png`

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 (화면 기준) |
| 마우스 | 조준 |
| 좌클릭 / 우클릭 | 스타일별 공격 / 스킬 |
| Space | 회피 덤블링 (낮은 벽 앞이면 공중제비로 넘기) |
| 1 ~ 7 | **싸우는 중 그 자리에서 캐릭터만 교체** (판은 그대로) |
| Tab | 캐릭터 목록 (판 진행 중이면 이어서) |
| Esc | 일시정지 / 범위 지정 취소 |
| F11 | 전체화면 |

## 전투 스타일 (문서의 액션 조작법 예 12~18)

| # | 스타일 | 좌클릭 | 우클릭 |
|---|---|---|---|
| 1 | 맨손 | 잽·잽·(텀)·스트레이트 — **한 놈만 팬다**, 같은 적 연타가 쌓이면 세짐, 스트레이트로 날린 적이 다른 적과 부딪히고 벽에 박힘 | 돌려차기 (바로 나감, 앞쪽 부채꼴 범위) |
| 2 | 검사 | 3연격, 공격 시 전진, 공격 중 방향 조절, 전방 자동 조준 | 돌진 베기 |
| 3 | 방패병 | 베기 / 막는 중엔 방패 밀치기 | 누르는 동안 막기 (80% 감소, 약간 밀림, 완벽한 막기) |
| 4 | 궁수 | 누르고 모아 쏘기 (가득 = 관통샷), 이동하며 모으기 | 3연발 |
| 5 | 마법사 | 마력탄 | 범위 지정 (WASD/마우스로 범위만 이동, 캐릭터 제자리) → 번개 지대 |
| 6 | 척탄병 | 누르면 포물선 미리보기, 떼면 수류탄 (벽 넘어감, 튕겨냄) | 발차기 |
| 7 | 거너 | 누르면 시전 게이지 → 광선, 쏘며 천천히 방향 조절, 맞아도 안 끊김, 과열 | 개머리판 |

적은 맵 가장자리에서 사방으로 몰려옵니다 (웨이브): 칼잡이(2연타), 총잡이(조준선 → 탄), 돌격병(돌진·내려찍기).
죽으면 맞은 방향으로 튕겨 나가며 쓰러집니다.

## 파일

| 파일 | 내용 |
|---|---|
| `main.lua` | 게임 전체 (맵, 스타일, 적 AI, 웨이브, 그리기, HUD, 자동 테스트) |
| `rig.lua` | 마네킹 8방향 3D 뼈대 + 무기 그리기 |
| `conf.lua` | 창 설정 |
| `build.ps1` | exe 만들기 (BOM 있는 UTF-8 로 저장해야 PowerShell 5.1 에서 한글이 안 깨짐) |
| `CLAUDE.md` | AI(Claude) 가 이어서 작업할 때 읽는 규칙·맥락 |
| `작업기록.md` | 지금까지 한 일, 결정한 것, 다음 할 일 |
| `이전버전/` | 예전 시도 (블록/결투풍 캐릭터의 악귀 사냥꾼) — 참고용 |
