# 배경 질감 만들기 (힉스필드)

이 폴더에 그림을 넣으면 게임이 자동으로 바닥·벽에 입힌다. 없으면 예전 단색(올리브 바닥, 베이지 상자) 그대로.

## 파일 이름 (꼭 이대로)
| 파일 | 어디에 | 그림 한 장이 덮는 크기 |
|---|---|---|
| `floor.png` | 바닥 전체 | 4m × 4m (캐릭터 키 약 1.8m) |
| `wall_top.png` | 상자·벽의 윗면 | 2m × 2m |
| `wall_front.png` | 상자·벽의 앞면 (그림 **아래쪽이 땅**) | 2m × 2m |

- `.jpg` 도 된다. 정사각형 1024×1024 또는 2048×2048 추천.
- 셋 중 하나만 넣어도 된다 (없는 건 예전 단색).
- 덮는 크기를 바꾸려면 `main.lua` 의 `BG_M = { floor = 4, wall_top = 2, wall_front = 2 }`.
- 넣은 뒤 `build.ps1` 로 빌드하면 exe 안에 같이 들어간다.

## 잘 나오게 하는 요령
- **이음매 없이 반복(seamless, tileable)** 이 가장 중요하다. 게임이 그림을 바둑판처럼 이어 붙인다. 이어지는 곳에 선이 보이면 다시 뽑거나 seamless 기능을 쓴다.
- **바닥·윗면은 바로 위에서 내려다본 그림(top-down, orthographic)**, 원근·소실점이 없어야 한다. 게임이 알아서 비스듬히 눌러 그린다.
- **앞면은 정면에서 평평하게 본 그림(front view, flat)**.
- 그림자·빛 방향이 강하면 이어 붙였을 때 티가 난다 → **고르게 밝은 조명(even, diffuse lighting)**.
- 캐릭터가 잘 보이도록 바닥은 **채도·대비를 낮게**. 너무 화려하면 마네킹과 체력바가 묻힌다.
- 글자·사람·물체(상자, 풀 무더기 같은 큰 것)는 넣지 않는다 → 반복될 때 똑같은 게 줄지어 보인다.

**도트용 추가 규칙**
- 힉스필드는 1024×1024 로 뽑히지만 도트 한 칸이 여러 픽셀로 뭉개져 나온다 → 받은 뒤 **작게 줄여서(가장 가까운 점 방식) 저장**한다. 화면에서 도트 한 칸 = 2px 가 되게:
  - `floor` (4m = 화면 160px) → **80×80**
  - `wall_top`, `wall_front` (2m = 화면 80px) → **40×40**
- 게임도 질감을 흐리게 펴지 말고 **또렷하게(nearest)** 그려야 한다 (`loadBgTextures` 의 필터, 지금은 linear).
- 색 수를 적게(4~6색), 채도·대비 낮게. 1번 일반 프롬프트보다 단순한 무늬가 줄였을 때 깔끔하다.

## 넣고 나서 확인할 것
- 이어지는 곳에 줄이 보이나 (seamless 실패)
- 캐릭터·적·빨간 공격 예고가 바닥에 묻히지 않나
- 무늬 크기가 캐릭터에 비해 너무 크거나 작지 않나 → `BG_M` 숫자로 조절
